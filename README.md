# Notizzettel

Selbst gehostetes Notiz-Tool: ein Zettel, einfach losschreiben.

> Die vollständige Anleitung (Installation, systemd, NGINX Proxy Manager, Update,
> Backup, Notfall-Zugang) folgt mit dem Abschluss der Entwicklung.

## Schnellstart (Entwicklung)

```bash
node server.js
```

Danach im Browser `http://127.0.0.1:3100` öffnen. Voraussetzung: Node.js ≥ 22.13.
`node_modules/` ist eingecheckt – ein `npm install` ist nicht nötig.
